# Sistema de Reportes de Problemas Universitarios

## Descripción
Este proyecto consiste en desarrollar un sistema web que permita a los estudiantes registrar problemas que se presentan dentro de la universidad.

## Objetivo
Facilitar la comunicación entre los estudiantes y las autoridades universitarias mediante el registro y seguimiento de reportes.

## Problemas que se pueden reportar
- Problemas de infraestructura.
- Fallas en equipos.
- Problemas de internet.
- Problemas con los servicios universitarios.

## Estado del proyecto
Actualmente se encuentra en desarrollo.
